# Security Policy

## Reporting a Vulnerability

Please use this repository's GitHub private vulnerability reporting flow for
security reports. Do not disclose suspected vulnerabilities in public issues
or discussions before a fix is available.

Include the affected version, reproduction steps, and the security impact.
Reports receive an acknowledgement within 7 days. The maintainer will assess
the report, coordinate a fix where appropriate, and publish disclosure details
after users have had reasonable time to update.

## Scope

The supported code is the latest version on the default branch. Browser
profiles, cookies, Sync data, and other user data are intentionally outside
the application's write scope and should never be included in a report.
